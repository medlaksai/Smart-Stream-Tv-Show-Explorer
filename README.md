# 📺 Smart Stream TV Channels

Interface Smart Stream TV développée en **HTML**, **Tailwind CSS** et **JavaScript vanilla (ES6+)**.
Elle permet de parcourir un catalogue de chaînes, de rechercher en direct
et de prévisualiser la chaîne sélectionnée. Les données sont fournies par **MockAPI**.

## ✨ Features
- Panneau latéral listant les chaînes (numéro, logo, titre) groupées par catégorie
- Activation d'une chaîne avec mise en surbrillance et affichage de sa prévisualisation
- Barre « Recherche TV en direct » (filtrage par nom ou numéro)
- États de chargement (spinner) et d'erreur (réseau, 404, 500)

## 🛠️ Technologies
- HTML5 sémantique
- Tailwind CSS (classes utilitaires uniquement)
- JavaScript ES6+ (modules, async/await, map, filter, find)
- Fetch API et MockAPI
